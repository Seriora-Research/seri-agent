# seri 0.1.4

Since [v0.1.3](https://github.com/Seriora-Research/seri-agent/releases/tag/v0.1.3). `seri --version` reports `seri 0.1.4`. Refresh a compiled install with `seri update`, or pin this tag with `SERI_VERSION=v0.1.4`.

## Images

- Sibling `read_file` calls in one turn overlap. The tool awaits `fs/promises` instead of `readFileSync`. Cap, image sniff, and the write barrier stay the same.
- `read_file` returns PNG, JPEG, GIF, and WebP as image parts when the catalog model accepts image input. Magic bytes, not the filename.
- Ctrl-V of a screenshot in the live session input attaches those bytes to the next turn instead of typing garbage.
- Text-only models drop the image with a visible warning. The turn still finishes.
- Scheduled / unattended `read_file` never returns image bytes.

## Scheduler

- A live schedule tick no longer looks done if session mint fails. Cadence advances only in the same SQLite write as a real `schedule_runs` row. A crashed in-flight fire retries on the next tick instead of going silent.

## Memory

- The live TUI transcript keeps the newest 4096 rows. Session SQLite stays the full record. `/clear` still empties the live view. `measureCache` keys by entry so a front-drop does not reuse a stale height.
- `/rewind` and `/compact` reset the archivist cursor so a rewritten transcript is reviewed. A stored cursor past the current length is treated as unseen, not as already done.

## Compaction

- The summarizer is told that `Transcript`, `Previous recap`, and `Newly evicted turns` are historical source. A turn that asks to overwrite `goal` / `progress` / `blockers` / `nextSteps` is described in progress, not copied into those keys.
- `SERI_COMPACTION_THRESHOLD` is env then `config.json`, a number in `(0, 1]`. Invalid or unset keeps the loop default `0.5`. Drive and child dispatch pass it through. `/config` lists the key last.
- A compaction cut that lands on a tool result keeps the assistant tool-call with it when that pair still fits the preserve budget. A tool row that fills the budget by itself is still evicted as a unit.
- Compact shrinks only the model window. SQLite keeps the full turn list. `/rewind` still refuses to restore across a compaction barrier.
- The 0.5 trigger uses usable input (`contextWindow - maxOutputTokens`) when max output is smaller than the advertised window. Missing or oversized output keeps the old window-only denominator.

## Loop

- Each model call sends the advertised catalog `maxOutputTokens`. If that value is missing, it sends 32000 so OpenRouter does not reserve 65536. If OpenRouter still returns `can only afford N` and N is below that cap, the loop retries once at N. The summarizer stays at 32000. ChatGPT-plan Codex still omits the field.

## Catalog

- Live models.dev JSON is parsed at the catalog boundary. A bad row is skipped; an empty or unusable payload falls back to the bundled manifest the same way a network error does.
- `/model` and `/effort` read those parsed entries. Routing no longer picks a candidate by array index.

## Linux binary

- Linux compile defines `process.env.OPENTUI_LIBC` so a packed `seri` keeps one OpenTUI native. glibc for `bun-linux-x64`, `bun-linux-arm64`, and a host Linux `bun run build`. musl only when the target name includes `musl`. Darwin and Windows stay unset.

## Internals

- If MCP `listTools` throws after a successful dial, the client closes that handle before dropping it from the session pool. The original error is still the rejection.
- Checkpoint snapshot state is a union, not two independent flags. `Checkpointer` is a plain object (undo / rewind / resume behavior unchanged).
- `paths.ts` and `config.ts` no longer import each other. Reserved profile names are a module-level set.

## Install

macOS and Linux:

```sh
curl -fsSL https://seri-agent.seriora.ai/install.sh | bash
```

Windows (PowerShell, no admin):

```powershell
irm https://seri-agent.seriora.ai/install.ps1 | iex
```

Then `seri --version` / `seri doctor` / `seri update`.
